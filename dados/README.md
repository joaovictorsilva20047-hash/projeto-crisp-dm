# Dados do Projeto

Esta pasta contém a base de dados utilizada no projeto de análise de vendas de uma loja virtual.

O arquivo utilizado foi o Online Retail, disponibilizado pelo UCI Machine Learning Repository.

A base contém informações sobre produtos, quantidades vendidas, preços, datas das compras, clientes e países.

## Referência bibliográfica

CHEN, D. (2015). Online Retail. UCI Machine Learning Repository.

Disponível em: https://doi.org/10.24432/C5BW33.
