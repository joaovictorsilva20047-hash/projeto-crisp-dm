# Resultados

Esta pasta contém os gráficos e resultados obtidos durante a análise de vendas da loja virtual.

Foram desenvolvidas visualizações para apresentar:

- Os 10 produtos com maior faturamento;
- Os 10 países com maior faturamento;
- A evolução do faturamento mensal;
- Os 10 clientes com maior valor acumulado em compras.

Os gráficos foram desenvolvidos utilizando Python e a biblioteca Matplotlib, com o objetivo de facilitar a interpretação dos dados e dos resultados encontrados.
